Trying to make React Server-Side Rendering from create-react-app with express

## Setup
- npm install

## Development
```sh
# Build client/ using webpack
npm run dev

# Start development server
# run it on different terminal
npm run dev-server
```

## Production
```sh
# Create production build using react-scripts build
npm run build

# Create server build using webpack
npm run build-server

# Start production server
# Change directory to your project root
node server/index.js

# production build output `./dist`
```
